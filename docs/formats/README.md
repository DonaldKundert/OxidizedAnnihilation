# Format notes

Every claim carries a tag:

- **Known**: observed in the GOG install (Kingdoms + Iron Plague, GOG build 2.0.0.4) or documented and confirmed against it.
- **Believed**: community or TA-derived knowledge, or a pattern that holds in most files but has exceptions, not yet confirmed for Kingdoms.
- **Unknown**: still to be found out.

When a Kingdoms file disagrees with the TA docs, the file wins.
